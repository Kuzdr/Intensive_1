- 29.09.2026 — ВТОРАЯ жалоба «ничего не изменилось, количества прототипов не вижу».
  Настоящая причина оказалась не в интерфейсе: сервер был запущен 27.09 и работал
  на коде, написанном ДО всех правок (`/api/update/status` отвечал
  «Изменений нет», полей `counts_line`/`proto_report` в ответе не было вовсе).
  **Правило: любую правку `serve.py`/`build.py`/`protolib.py` нельзя
  «проверить на глаз», пока сервер не перезапущен.** Чтобы это больше не
  выглядело как «ничего не изменилось»:
  - `serve.stale_files()` сравнивает время старта процесса с временем изменения
    `serve.py`/`build.py`/`protolib.py`; `state['stale']` уходит в
    `/api/update/status`, панель на странице показывает жёлтое предупреждение
    сразу при загрузке, а окно сервера печатает предупреждение при старте;
  - порядок обновления изменён: **СНАЧАЛА ПРОТОТИПЫ** (быстрый и главный этап),
    потом сбор событий, потом сайт и публикация.
  Также исправлен баг: кнопка «Закрыть» у панели, показанной до нажатия
  «Обновить» (сохранённый результат / предупреждение), обращалась к пустой
  переменной `panel`; теперь работает `wireClose(box)`.
- 02.10.2026 — предупреждение «сервер устарел» перестало показываться впустую:
  `serve.stale_files()` теперь сравнивает ХЭШ содержимого файла, а не время его
  изменения (перезапись без изменений — не повод для предупреждения), и следит

  каждом обновлении, его правки применяются без перезапуска сервера. Из текста
  предупреждения убран устаревший подставляемый пример «проход по прототипам».
