# Карточки лекториев

Индивидуальные правила разбора источника (разд. 1б скилла `event-description`)
хранятся здесь: по одной карточке на лекторий. Шаблон ответа (формальные
поля → текст → HTML) при этом НЕ меняется — он един для всех.

Формат карточки:

```
## <Название лектория> (<город>)

- Источники: <откуда берём данные> (сайт организатора, Timepad и т.п.)
- Подзаголовок: <что писать в поле 3/6>
- ID события: <правило для поля 0>
- Онлайн: <есть/нет и как определяем>
- Место по умолчанию: <город, площадка из шаблона, если не сказано иначе>
- Прочее: <особенности разбора этой площадки>
```

## Astrocamp (Москва)

- Источники: Timepad (astrocamp.timepad.ru); событие без онлайн-части.
- Подзаголовок: «Лекторий Astrocamp».
- ID события: TP-<id Timepad> (Timepad сам восстанавливает организатора).
- Онлайн: нет; модалку Timepad «Получить ссылку на трансляцию» (есть в HTML,
  но на видимой странице отсутствует) подтверждением онлайн-трансляции
  НЕ считаем — по умолчанию событие полностью офлайн.
- Прочее: аннотация строится по абзацам источника; цикл/подзаголовок
  источника НЕ теряем (первым абзацем аннотации).

## «Живой город» (Тверь)

- Источники: сайт организатора.
- Подзаголовок: лекторий «Живой город».
- Место по умолчанию: Тверь, лекторий «Живой город» — если не сказано точнее.
- Прочее: почти все данные видны в тексте страницы, ничего не спрятано.

## «Прямая речь» (Москва и другие города)

- Источники: сайт организатора; часть данных спрятана в мета-полях страницы
  (og:title / og:description / og:url, цена — в JSON-LD/microdata): перед
  прототипом вытащить эти поля из HTML источника и сверить с видимым текстом;
  расхождение показать, но включать то, что видно на странице.
- Подзаголовок: «Прямая речь».
- Онлайн: событие может проходить и офлайн, и в ОНЛАЙНе (трансляция) — место
  в шапке пишем ОБА: «…, Москва, «Прямая&nbsp;речь» и&nbsp;ОНЛАЙН»; онлайн
  отдельной строкой НЕ выносим; если есть трансляция, цена двойная
  (офлайн-билет и онлайн-трансляция) — выводим ОБЕ.
- Прочее: «Прямая речь» в адресе — площадка, на которой проводится лекция
  (могут быть и другие); низ описания (адрес, проезд, телефон) дорабатывается —
  как его составлять, ещё обсуждаем (см. историю 20.09.2026).

## Фестиваль NAUKA 0+ (Москва и другие города)

- Источники: сайт festivalnauki.ru (страницы /program/...).
- Подзаголовок: Фестиваль NAUKA&nbsp;0+.
- ID события: формат `0+-<гг><мм><дд>-<Фамилия латиницей>`
  (например 0+-261010-Oganov — событие 10.10.2026 Артёма Оганова).
- Онлайн: есть отдельные онлайн-события (на сайте фильтр «Онлайн»); для
  события смотрим поля страницы.
- Место по умолчанию: если указано «Центральная площадка, Москва» —
  площадка «Фундаментальная библиотека МГУ», полное название —
  «Фундаментальная библиотека МГУ им.&nbsp;М.&nbsp;В.&nbsp;Ломоносова»,
  адрес: Москва, Ломоносовский проспект, 27.
- Прочее:
  - События «Своя площадка» на региональных площадках: пометку «Своя
    площадка» ИГНОРИРУЕМ; площадка — организация-участник (университет,
    институт и т.п.), у которой проходит событие (например, для события
    «ИИ сегодня…» в Саратове — СГУ им. Н. Г. Чернышевского).
  - «Аудитория Актовый зал» в источнике — в описании/адресе пишем
    «актовый зал» (строчными).
  - Строка «будет интересно всем» в блоке характеристик события — сигнал
    для формального поля 14 «Аудитория»: «для всех» (факультативное поле;
    заполняем, когда аудиторию можно определить по источнику).
  - Возраст и стоимость на страницах события фестиваля могут не указываться —
    тогда в полях 11/12 пишем «—», не выдумываем.
  - Если автора нет на «Элементах» (автор новый) — его фото берём из анонса
    лекции на festivalnauki.ru (страница программы /program/): поле 7.5
    заполняем по фото из анонса фестиваля (правило согласовано 24.09.2026).

## Центр «Архэ» (Москва, СПб; онлайн)

- Источники: сайт организатора arhe.msk.ru — основной, первый по приоритету;
  Timepad — второй. У «Архэ» ДВА timepad-аккаунта:
  tsentr-arhe-v-sankt-peter.timepad.ru и arhe-events.timepad.ru (один и тот же
  анонс может появиться в обоих — под разными номерами); проверять оба.
- Подзаголовок: «Научно-популярный лекторий "Архэ"» (так Архэ-события
  подписаны на «Элементах»; подтверждено пользователем 25.09.2026).
  ИСКЛЮЧЕНИЕ: у лекций КУРСА полная схема полей 3–6 — в скилле
  event-description, разд. 3а п. 5:
  - поле 3: «Название лекции»<br>Лекция N курса Автора «Название курса»;
  - поле 4: «Название лекции». Лекция N курса Автора «Название курса»;
  - поле 5: Название лекции (без кавычек);
  - поле 6: Название курса. Лекция N.
  Пример (курс «Пять историй богатства», лекция 1 «Великобритания…»):
  поле 6 = «Пять историй богатства»: как страны становятся великими
  и&nbsp;почему теряют свой успех. Лекция&nbsp;1 (название курса УЖЕ
  содержит «ёлочки» — см. п. 5 про „лапки“). НЕ лекторий.
- ID события: TP-<id Timepad> (id берём из любого timepad-анонса события;
  например, TP-4207848).
- Онлайн: трансляции лекций идут на arhe.msk.ru/stream. Один и тот же анонс
  может быть офлайн в одном timepad-аккаунте и онлайн в другом — сверяем оба
  и в прототипе показываем всё, что найдено (формат «офлайн и ОНЛАЙН» или
  «просто ОНЛАЙН» — по факту трансляции).
- Место по умолчанию: если в источниках прямо указан город/площадка — берём
  их; для чисто онлайн-лекций — ОНЛАЙН.
- Прочее:
  - У лекций на arhe.msk.ru два формата страниц: `?p=<число>` и
    `?tribe_events=<название-по-русски-транслитом>` (второй появляется раньше,
    содержание обычно такое же или близкое). Предпочтителен формат с числом —
    сначала ищем его.
  - Другие варианты страницы лекции ищем в разделах сайта: календарь
    (arhe.msk.ru/?post_type=tribe_events), «Лекторий» (arhe.msk.ru/?page_id=369),
    «Архэ СПб» (arhe.msk.ru/?page_id=32233), «Архэ Лайт»
    (arhe.msk.ru/?page_id=77150), «Архэ Курсы» (arhe.msk.ru/?page_id=332),
    а также в обоих разделах ...timepad.ru/events/. В поле «Источники»
    указываем ВСЕ найденные варианты страниц события (каждый на новой строке).
  - Старые циклы и курсы с тем же лектором на сайте (например, «Новости
    астрономии с Кириллом Масленниковым», arhe.msk.ru/?page_id=88427) —
    НЕ путать с текущим анонсом лекции.
  - Лекции «Архэ» часто платные онлайн-трансляции: стоимость трансляции
    (например, «Стоимость трансляции лекции — 900 рублей») идёт в поле 11.
  - Контакты «Архэ»: arhe.msk@gmail.com, https://t.me/centrarhe.
