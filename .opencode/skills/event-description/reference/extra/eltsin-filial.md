# Филиал Ельцин Центра в Москве — образец «Дополнительной информации»

Перенесено из раздела «Образцы «Дополнительной информации» по лекториям». Общие правила — в SKILL.md, разд. 5а.

**Филиал Ельцин Центра в Москве** (прототипы четырёх лекций октября–ноября
2026; основной источник — сайт Ельцин Центра, второй — Timepad):

- абзац 1 — вход и регистрация (с выделением `<b>` на слове «свободный»;
  ссылка на регистрацию — прямая, на словах «предварительной регистрации»):
  `<p>Вход <b>свободный</b>. Необходима <a href="https://filial-eltsin-tsentra-v-m.timepad.ru/event/<id>/#register" target="_blank">предварительная регистрация</a>. 18+.</p>`
  (приписка возраста в конце абзаца — ТОЛЬКО по общему правилу
  «Возрастные ограничения» выше: у 18+ и у детских мероприятий; «12+»
  у лекций цикла в «Дополнительную информацию» НЕ добавляется — только
  в поле 12. В прототипах цикла октября–ноября 2026 «12+» уже стоит в
  конце абзаца — событие готово и не переделывается);
- абзац 2 — АДРЕС (общий блок с выделениями `<b>` и ссылкой на карту в
  «Проезд»):
  `<p><b>Адрес:</b> Москва, ул.&nbsp;Малая&nbsp;Никитская, дом&nbsp;12, стр.&nbsp;1, Филиал Ельцин Центра в&nbsp;Москве. Усадьба Долгоруковых-Бобринских. <зал>.<br>

  <b>Проезд:</b> метро «Баррикадная», «Арбатская», «Пушкинская», «Тверская». <a href="https://yandex.ru/maps/-/CPAPMZ5V" target="_blank">Карта</a>.</p>`
  (у Аузана — «Центральный вход, 2 этаж, бальный зал»; у лекций цикла
  «ИИ в усадьбе» — «Лекционный зал 2, 1 этаж»);
- перед блоком ссылок — разделительный комментарий `<!-- @@@ -->`;
- абзац 3 (ссылки) — с классом `small`, два источника:
  `<p class="small">Информация о&nbsp;лекции <a href="https://yeltsin.ru/affair/<slug>/" target="_blank">на сайте Ельцин Центра</a>.<br>

  Информация о&nbsp;лекции <a href="https://filial-eltsin-tsentra-v-m.timepad.ru/event/<id>/" target="_blank">на TimePad</a>.</p>`
  Основной источник — разрешённый `yeltsin.ru` (домен в `ORGANIZER_NAMES`),
  даже если вторичный источник — Timepad (см. карточку лектория в
  `reference/lectories.md`).

Лекции цикла «ИИ в усадьбе»: в конце аннотации, внутри `</blockquote>`,
список лекций цикла без ссылок, как на «Архэ» (разд. 3а): нумерованный
`<ol>`, после списка — приписка «Все спикеры курса — учёные Центра
искусственного интеллекта Сколтеха.» по источнику. В подзаголовок лекций
цикла (поле 4) пишем ровно «Цикл Сколтеха «ИИ в&nbsp;усадьбе»».
У лекций ВНЕ цикла (как Аузан, 2.10) — ни подзаголовка, ни списка.
