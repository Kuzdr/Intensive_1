# Medio Modo — образец «Дополнительной информации»

Перенесено из раздела «Образцы «Дополнительной информации» по лекториям». Общие правила — в SKILL.md, разд. 5а.

**Medio Modo** (прототип MM-261003-Krotovye-nory, лекция О. Сажиной
«Как искать кротовые норы?», 3.10.2026, БЕН РАН; образец — опубликованная
лекция того же лектория на той же площадке 450571, принят пользователем
29.09.2026):

- абзац 1 — стоимость и покупка:
  `<p>Стоимость билетов: <b>от 1200&nbsp;руб.</b> <a href="https://mediomodo.ru/<slug>" target="_blank">Купить билет</a>.</p>`
  (в источнике верхняя граница диапазона не указана — пишем «от …»;
  слово «билетов» — как в образце, во множественном числе);
- блок «Контакты организатора» (телефон — всегда по общему формату
  `+7(999)999-99-99`; почта и прочие способы связи — из источника):
  `<p><b>Контакты организатора:</b> +7(915)248-97-37. <b>Почта:</b> <a href="mailto:<почта>" target="_blank"><почта></a>.</p>`;
- блок «Адрес» + «Проезд» + «Карта» (адрес и проезд площадки — из образца
  450571, если в источнике их нет; сайт площадки — ссылкой в её названии):
  `<p><b>Адрес:</b> Москва, Малый Знаменский пер.&nbsp;11/11, <a href="https://www.benran.ru/" target="_blank">Библиотека по естественным наукам Российской академии наук</a> (БЕН РАН).<br>

  <b>Проезд:</b> метро «Боровицкая», «Библиотека им.&nbsp;Ленина», «Кропоткинская», «Арбатская», «Александровский сад». <a href="https://yandex.ru/maps/-/CGw7q4y~" target="_blank">Карта</a>.</p>`
  (аббревиатура «БЕН РАН» и в шапке, и здесь — обычным пробелом, как в
  образце; в формальном поле 8 площадка — КОРОТКОЕ название из списка мест);
- разделительный комментарий `<!-- @@@ -->` — по общему правилу раздела
  выше, НЕПОСРЕДСТВЕННО перед блоком ссылок, а не перед «Контактами
  организатора» (в образце 450571 он стоит раньше, но нам он нужен как
  метка «здесь меняется ссылка на источник», когда новое описание
  собирается копированием старого);
- блок ссылок, два абзаца с классом `small`:
  `<p class="small">Информация о&nbsp;лекции <a href="https://mediomodo.ru/<slug>" target="_blank">на сайте Medio Modo</a>.</p>`
  `<p class="small">Medio Modo <a href="https://vk.com/mediomodo" target="_blank">ВКонтакте</a> и <a href="https://t.me/mediomodo" target="_blank">в&nbsp;Телеграме</a>.</p>`
  (название лектория — обычными пробелами, разд. 2 `proofreading`);
- НЕ переносим из источника «пугалку» про видеосъёмку («Видеосъемка
  мероприятия без письменного согласия правообладателя запрещена в
  соответствии со ст. 1229 и 1270 ГК РФ») — по решению пользователя
  29.09.2026: покупатель увидит это при покупке билета;
- возраст «6+» в «Дополнительную информацию» НЕ выносим (общее правило
  возраста выше): остаётся только в поле 12.
