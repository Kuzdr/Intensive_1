Правила:
- блок адреса/проезда/карты — дословно с «Элементов» 447884/448516, ссылка на
  карту `https://yandex.ru/maps/-/CKQgMZPL` не опускается;
- ссылка на сайт библиотеки и соцсети — отдельным абзацем `class="small"`,
  НЕ склеивается `<br>` со ссылкой-источником о лекции;
- ссылка-источник на TimePad — последний абзац, одна на событие, отдельным абзацем;
- регистрация — только через `#register` актуальной карточки Timepad,
  текст ссылки «предварительная регистрация» без слов «на TimePad»;
- возраст в источнике не указан → в доп. информации его нет (и в поле 12
  тоже пусто).
