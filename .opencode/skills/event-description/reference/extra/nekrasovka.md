# Библиотека им. Н. А. Некрасова — образец «Дополнительной информации»

Основа — опубликованное событие «Элементов» **450775** («От Басмании к
звёздам», лекция Алексея Николаева, 25.10.2026, 13:00 — та же площадка и
тот же день, что и прототип NK-9077). Формулировки и порядок блоков взяты
оттуда; ссылки и зал заменены под конкретное событие.

## Блоки по порядку

1. **Вход/регистрация** (ссылка — на самих словах о регистрации, правило
   14.10.2026). В образце 450775 (два входа: сайт + Timepad):

   ```html
   <p>Вход <b>свободный</b>. Зарегистрируйтесь <a href="https://nekrasovka.ru/afisha/25-10-2026/9070" target="_blank">здесь</a> или <a href="https://basmania.timepad.ru/event/4226792/#register" target="_blank">здесь</a>.</p>
   ```

   При ОДНОЙ форме регистрации (страница события, без Timepad) — как в
   NK-9077:

   ```html
   <p>Вход <b>свободный</b> по <a href="https://nekrasovka.ru/afisha/25-10-2026/9077" target="_blank">предварительной регистрации</a>. 18+.</p>
   ```

   Возраст 18+ добавляется в этот же абзац (18+ — из двух случаев, когда
   возраст выносится в «Доп. информацию», правило 28.09.2026).

2. **Адрес + проезд + карта** (карта — точная ссылка СО СТРАНИЦЫ СОБЫТИЯ
   (`yandex.ru/maps/-/C6upr42e`, проверено 22.10.2026: ведёт на «Библиотека
   им. Н. А. Некрасова, Бауманская ул., 58/25с14»). Ссылка карты из образца
   450775 `yandex.ru/maps/-/C6ALmLII` ведёт на ГЕНЕРАЛЬНУЮ карту Москвы и
   для новых событий НЕ используется):

   ```html
   <p><b>Адрес:</b> Москва, ул.&nbsp;Бауманская, д.&nbsp;58/25, стр.&nbsp;14. Библиотека им.&nbsp;Н.&nbsp;А.&nbsp;Некрасова, конференц-зал, 5&nbsp;этаж.<br>

   <b>Проезд:</b> метро «Бауманская». <a href="https://yandex.ru/maps/-/C6upr42e" target="_blank">Карта</a>.</p>
   ```

   Нюансы:

   - адрес — ПО ИСТОЧНИКУ события (правило 15.10.2026): в 450775 зал
     «Арт-пространство, 2 этаж», в NK-9077 — «конференц-зал, 5 этаж»
     (площадка события);
   - НАЗВАНИЕ ПЛОЩАДКИ — ОТДЕЛЬНЫМ ПРЕДЛОЖЕНИЕМ через точку (правило
     14.10.2026): `… стр.&nbsp;14. Библиотека им.&nbsp;Н.&nbsp;А.&nbsp;Некрасова, конференц-зал, 5&nbsp;этаж.`
     — в опубликованном 450775 площадка стоит через запятую, но правило
     важнее образца;
   - организация («Библиотека им. Н. А. Некрасова») в адресе стоит ПЕРЕД
     залом (правило 15.10.2026);
   - между `<br>` и `<b>Проезд:</b>` — ровно одна пустая строка.

3. **Разделитель** `<!-- @@@ -->` — одним абзацем непосредственно перед
   блоком ссылок.

4. **Блок ссылок** (`class="small"`). В образце 450775 три ссылки (сайт
   библиотеки, сайт музея «Басмания», Timepad); для события без Timepad —
   только сайт библиотеки:

   ```html
   <p class="small">Информация о&nbsp;лекции <a href="https://nekrasovka.ru/afisha/25-10-2026/9077" target="_blank">на&nbsp;сайте библиотеки им.&nbsp;Н.&nbsp;А.&nbsp;Некрасова</a>.</p>
   ```

   После `<br>` внутри блока ссылок — пустая строка (правило 01.10.2026),
   если ссылок несколько.

## Чего в образце нет

- Телефон: в 450775 нет → не добавляем (телефон факультативен и берётся из
  образца площадки).
- Онлайн/трансляция: события площадки офлайн → поля 2/8 без «и&nbsp;ОНЛАЙН».
