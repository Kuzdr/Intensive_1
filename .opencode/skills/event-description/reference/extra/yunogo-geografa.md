# «Лекторий юного географа» (географический факультет МГУ) — образец «Дополнительной информации»

Перенесено из раздела «Образцы «Дополнительной информации» по лекториям». Общие правила — в SKILL.md, разд. 5а.

Эталон — опубликованные события этого лектория на «Элементах»: **448323**
(Андрей Бредихин, 15.03.2025) и **445877** (Алексей Медведков, 11.11.2023);
старый образец — 435750. Лекция для школьников, **очно + онлайн**,
бесплатно, при поддержке Русского географического общества. Источник — сайт
географического факультета МГУ (`geogr.msu.ru`).

«Дополнительная информация» — это ВСЁ, что идёт после `</blockquote>`
аннотации (шапка + преамбула + `<KLBLOCK>` + `<blockquote>` — это ещё
описание). Набор и порядок блоков — как в образцах 448323/445877.

- абзац 1 — продолжение лектория и аудитория (дословно с «Элементов»):
  `<p>Географический факультет продолжает <b>лекторий для школьников</b>. Приглашаются учащиеся от 7 классов и старше.</p>`
- абзац 2 — о лектории (дословно):
  `<p>Ежемесячно преподаватели географического факультета будут выступать с лекциями, посвященными различным аспектам географии и постараются сделать так, чтобы это было не только познавательно, но и интересно. Лекторий&nbsp;— прекрасная возможность познакомиться с факультетом и преподавателями, узнать о географии больше, чем изложено в учебниках.</p>`
- абзац 3 — поддержка РГО (есть в 448323, нет в 445877 — включаем, если так
  сказано в анонсе):
  `<p>Лекция проводится при поддержке Русского географического общества.</p>`
- абзац 4 — регистрация (по правилу «РЕГИСТРАЦИЯ — ВСЕГДА ССЫЛКОЙ НА САМИХ
  СЛОВАХ О РЕГИСТРАЦИИ», SKILL.md разд. 5а; ссылка СВОЯ на каждую лекцию —
  Яндекс-форма `forms.yandex.ru/cloud/<id>/` либо портал «Горизонты»

  Ссылка для подключения дистанционных участников будет выслана накануне лекции по адресу электронной почты, указанному при регистрации.</p>`
  (вариант старого образца 445877 — отдельные абзацы «Для очной формы…» и

  `<p><b>Адрес:</b> Москва, Ленинские горы, д.&nbsp;1, Главное здание МГУ, географический факультет, 18 этаж, аудитория 1807. Проход в Главное здание&nbsp;— со стороны Клубной части МГУ (вход со стороны ул. Академика Хохлова).<br>

- разделительный комментарий `<!-- @@@ -->` перед блоком ссылок (в образцах

- блок ссылок (в образцах один абзац с `<br>` и подпись «Подробнее о лекции» —

Для описания (не для «Доп. информации»): шапка — «<День>, <DD>&nbsp;месяца
<YYYY>&nbsp;года, 16:00–17:30, Москва, географический факультет МГУ
и&nbsp;ОНЛАЙН.» (порядок слов — «географический факультет МГУ», НЕ «МГУ,
географический факультет» — правило пользователя 15.10.2026); затем преамбула
«Лекция <b><i>Имени Фамилии</i></b> <b>«Название».</b> Лекция проводится в
