# Лог недоступности сайтов-источников

Отдельный журнал (правило пользователя 10.10.2026): при НЕУДАЧНОЙ
попытке запроса к сайту (elementy.ru, Timepad, сайт организатора,
поисковик, websearch-провайдер и т.п.) любая ошибка записывается сюда,
и об этом сообщается пользователю в чате. Если сайт недоступен
(несколько ошибок подряд, transport error, HTTP 5xx/403) — повторяем
попытку через 1 минуту; если снова неудачно — ещё раз через 5 минут;
дальше — по решению пользователя (продолжаем с другим экраном/файлом/
полем или откладываем оставшийся блок).

Порядок записи: дата (ГГГГ-ММ-ДД и время), какой сайт/URL, тип ошибки,
сколько было попыток и через какие интервалы, чем закончилось.
