Скелеты авторов для блока "authors" в prototype.json.
Три варианта (см. README.md, раздел "Авторы"). Скопировать нужный объект
в массив "authors" и заменить всё в угловых скобках.

================================================================================
ВАРИАНТ 1. Автор УЖЕ есть на «Элементах» (on_elementy: true).
Блок «Об авторе» (7.4, block_html, 7.5) копируется с «Элементов» ДОСЛОВНО.
Поле 7.6 НЕ заполняем (фото уже в базе «Элементов»).
================================================================================

{
  "name": "<Имя Фамилия>",
  "photo": "<URL фото с «Элементов»>",
  "on_elementy": true,
  "block_html": "<p><Описание автора с «Элементов» дословно.></p>",
  "fields": [
    { "n": "7.1", "name": "Инвертированное имя", "value": "<Фамилия Имя>" },
    { "n": "7.2", "name": "Стандартное имя", "value": "<Имя Фамилия>" },
    { "n": "7.3", "name": "Полное имя", "value": "<Имя Отчество Фамилия — убрать, если нет отчества>" },
    { "n": "7.4", "name": "Описание автора", "value": "<p><Описание автора с «Элементов» дословно (HTML-форма, как в block_html).></p>" },
    { "n": "7.5", "name": "Фото из источников", "value": "<URL фото с «Элементов»>" }
  ]
}
